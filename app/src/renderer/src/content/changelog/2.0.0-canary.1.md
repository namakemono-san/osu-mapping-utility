## Welcome to osu! mapping utility v2

今回のアップデートでは v1 から多くのものを引き継ぎつつ  
将来に向けて全ての基盤となる箇所を刷新しています。

### ゼロからの再構築

アプリケーションのフロントエンド、バックエンドをすべてゼロから書き直したことで新機能の追加が容易になり、パフォーマンスも向上しました！

### ツール名の変更と統合

v1 からツール名と構成を見直しました。

- **Beatmap Clone** → **Mapset Cloner**
- **Beatmap Customizer** → **Mapset Tweaker**
- **Beatmap Preview** → **Mapset Preview**
- **Metadata Checker** → **Mapset Checker**
- **Audio Analyzer** → **Audio Inspector**
- **Media Downloader** と **Image Downloader** は **Media Downloader** として統合

### Mapset Cloner

- "Keep Kiai" オプションを廃止
  - タイミングポイントのリセット時は常にKiaiも対象に含まれます。
- "Remove Skin Files" オプションを廃止
  - スキンファイルは常に除外されます。

### Metadata Editor

- **Background Setter** を追加
  - 各難易度の背景画像とオフセットをインタラクティブに調整でき、太鼓専用のプレビューオーバーレイを内蔵しているため直感的に操作が可能です。

### Audio Inspector

v1 の Audio Analyzer から大幅に機能を拡充しました。

- フォーマット・ビットレート・サンプルレートの確認
- カットオフ周波数の推定によるロッシー再エンコードの検出
- スペクトログラムの生成・ダウンロード

### Spread Analyzer

廃止しました。

### 未移植のツール

以下のツールは現在 v2 に存在しませんが、今後追加予定です。

- Mapset Preview
- Mapset Checker
- Offset Calibrator
